# Enforcement

Each architecture rule and what makes it fail when broken. A rule with nothing in the second column relies on review alone; when an agent breaks one of those twice, run `/correct` and move it up to a check. Keep this table current in the same change that adds, enforces, or drops a rule.

| Rule                                                                                                                                                                                 | Enforced by                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| The domain never depends on `app/Http`                                                                                                                                               | `arch()` in `tests/Unit/ArchitectureTest.php`                                                                            |
| A context's internals (Models, Enums, Policies, Services) are used only by itself, `App\Models`, factories, seeders, and `app/Http`; its public surface only by the domain and those | `arch()` per discovered context in `ArchitectureTest`                                                                    |
| The shared kernel depends on no context                                                                                                                                              | `arch()` in `ArchitectureTest`                                                                                           |
| Actions end in `Action` and have `handle()`; Queries end in `Query`                                                                                                                  | `arch()` in `ArchitectureTest`                                                                                           |
| Domain exceptions extend `DomainException`; contexts never throw `ValidationException`                                                                                               | `arch()` in `ArchitectureTest` (Authentication is the listed exception)                                                  |
| Controllers never use `DB` or query models                                                                                                                                           | `arch()` and "keeps Eloquent queries out of controllers" in `ArchitectureTest`                                           |
| Aggregate invariants hold for every caller                                                                                                                                           | `GuardsInvariants` (events, silenced events, bulk writes); `tests/Feature/AccessControl/AccessControlInvariantsTest.php` |
| No bulk writes on guarded aggregates                                                                                                                                                 | `GuardedBuilder`; "guards invariants only through GuardsInvariants" in `ArchitectureTest`                                |
| No raw `DB::table()` or SQL writes on guarded tables                                                                                                                                 | `tests/Feature/GuardedTablesTest.php`, with tables discovered from `GuardsInvariants` models                             |
| Every Action, Query, and domain exception is listed in its context rule file                                                                                                         | `ArchitectureTest`                                                                                                       |
| HTTP and feature test folders are named after a context                                                                                                                              | `ArchitectureTest`                                                                                                       |
| Agent skills have valid frontmatter, licenses, and live path references                                                                                                              | `tests/Feature/AgentToolingTest.php`                                                                                     |
| Committed `CLAUDE.md` and `AGENTS.md` match `.ai/guidelines`                                                                                                                         | `tests/Feature/AgentToolingTest.php`                                                                                     |
| Code style and types                                                                                                                                                                 | Pint, `vp check`, PHPStan level 7, all in `composer ci:check`                                                            |
| Protected controller actions call `Gate::authorize()` first                                                                                                                          | —                                                                                                                        |
| Policies check permissions, never role names                                                                                                                                         | —                                                                                                                        |
| Form Requests contain no `authorize()` logic                                                                                                                                         | —                                                                                                                        |
| Routes carry no permission middleware                                                                                                                                                | —                                                                                                                        |
| Inertia props and API resources list every exposed field                                                                                                                             | —                                                                                                                        |
