# Enforcement

Each architecture rule and what makes it fail when broken. A rule whose enforcer is only partial says so; when an agent breaks one of those twice, run `/correct` and move it up to a check. Keep this table current in the same change that adds, enforces, or drops a rule.

| Rule                                                                                                                                                                                 | Enforced by                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The domain never depends on `app/Http`                                                                                                                                               | `arch()` in `vendor/shipwithian/shipkit-core/tests/ArchitectureTest.php`                                                                                                                                                                                                       |
| A context's internals (Models, Enums, Policies, Services) are used only by itself, `App\Models`, factories, seeders, and `app/Http`; its public surface only by the domain and those | `arch()` per discovered context in `ArchitectureTest`                                                                                                                                                                                                                          |
| The shared kernel (`ShipKit\Core`) never depends on the application                                                                                                                  | `arch()` in `vendor/shipwithian/shipkit-core/tests/CoreBoundaryTest.php`                                                                                                                                                                                                       |
| ShipKit's checks run in every project                                                                                                                                                | `php artisan shipkit:verify` in `composer ci:check` fails when the `ShipKit` testsuite is missing from `phpunit.xml`                                                                                                                                                           |
| Guarded models are mapped and use `GuardsInvariants`                                                                                                                                 | `ShipKitServiceProvider` refuses to boot with an unguarded mapped model; `shipkit:verify` also fails on an unmapped one or a missing `config/shipkit.php`                                                                                                                      |
| Actions end in `Action` and have `handle()`; Queries end in `Query`                                                                                                                  | `arch()` in `ArchitectureTest`                                                                                                                                                                                                                                                 |
| Domain exceptions extend `DomainException`; contexts never throw `ValidationException`                                                                                               | `arch()` in `ArchitectureTest` (contexts listed in `shipkit.architecture.contexts_using_framework_exceptions` are exempt from the second)                                                                                                                                      |
| Controllers never use `DB` or query models                                                                                                                                           | `arch()` and "keeps Eloquent queries out of controllers" in `ArchitectureTest`                                                                                                                                                                                                 |
| Aggregate invariants hold for every caller                                                                                                                                           | `GuardsInvariants` (events, silenced events, bulk writes); `tests/Feature/AccessControl/AccessControlInvariantsTest.php`, `tests/Feature/CreationInvariantsTest.php`                                                                                                           |
| No query-builder writes on guarded aggregates, even for one row                                                                                                                      | `GuardedBuilder`, which opens its single-record path only for `GuardsInvariants`' own writes; `vendor/shipwithian/shipkit-core/tests/GuardedWritesTest.php`; "guards invariants only through GuardsInvariants" in `ArchitectureTest`                                           |
| Every Laravel builder method is classified as guarded, rejected, or safe                                                                                                             | `vendor/shipwithian/shipkit-core/tests/BuilderClassificationTest.php` fails on an unclassified method, and on a guarded or rejected write `GuardedBuilder` does not override; core's `composer.json` allows only the classified Laravel major                                  |
| No writes through `toBase()` or `getQuery()`                                                                                                                                         | "never writes through the base query builder" in `vendor/shipwithian/shipkit-core/tests/GuardedTablesTest.php` (a chained call; a base builder kept in a variable still relies on review)                                                                                      |
| No raw `DB::table()` or SQL writes on guarded tables                                                                                                                                 | `vendor/shipwithian/shipkit-core/tests/GuardedTablesTest.php`, with tables discovered from `GuardsInvariants` models                                                                                                                                                           |
| Every Action, Query, and domain exception is listed in its context rule file                                                                                                         | `ArchitectureTest`                                                                                                                                                                                                                                                             |
| HTTP and feature test folders are named after a context                                                                                                                              | `ArchitectureTest`                                                                                                                                                                                                                                                             |
| Agent skills have valid frontmatter, licenses, and live path references                                                                                                              | `tests/Feature/AgentToolingTest.php`                                                                                                                                                                                                                                           |
| Shared rules, skills, and guidelines come from `shipkit-core`, never a project copy, and `boost.json` lists the package                                                              | "takes the shared guidance from shipkit-core" in `tests/Feature/AgentToolingTest.php`; every core rule file must appear in `.ai/rules/index.md`                                                                                                                                |
| Committed `CLAUDE.md` and `AGENTS.md` match `.ai/guidelines` and `shipkit-core`'s guidelines                                                                                         | `tests/Feature/AgentToolingTest.php`                                                                                                                                                                                                                                           |
| Code style and types                                                                                                                                                                 | Pint, `vp check`, PHPStan level 7, all in `composer ci:check`                                                                                                                                                                                                                  |
| Protected controller actions call `Gate::authorize()` first                                                                                                                          | `tests/Feature/RouteAuthorizationTest.php`: every action behind `auth` middleware, parsed; only `$user = $request->user();` may precede it                                                                                                                                     |
| Policies check permissions, never role names                                                                                                                                         | "authorizes policies through permissions, never role names" in `ArchitectureTest`                                                                                                                                                                                              |
| Form Requests contain no `authorize()` logic                                                                                                                                         | `arch()` in `ArchitectureTest`                                                                                                                                                                                                                                                 |
| Routes carry no permission middleware                                                                                                                                                | `tests/Feature/RouteAuthorizationTest.php` (`can:`, `role:`, `permission:` on any app route)                                                                                                                                                                                   |
| Inertia props and API resources list every exposed field                                                                                                                             | "lists every exposed field" in `ArchitectureTest` catches `toArray()`-style dumps; a raw model passed as a prop still relies on review                                                                                                                                         |
| Inertia pages receive typed props classes, never arrays                                                                                                                              | `vendor/shipwithian/shipkit-core/tests/InertiaPayloadTest.php` (`Inertia::render()`, `inertia()`, `Route::inertia()`)                                                                                                                                                          |
| Frontend payload types are generated from PHP and match it                                                                                                                           | `composer ci:check` runs `composer types:generate` and fails on a diff in `resources/js/types/generated.ts`; `npm run types:check` then checks pages against it                                                                                                                |
| API routes that change state are throttled                                                                                                                                           | `tests/Feature/ApiRouteConventionsTest.php`                                                                                                                                                                                                                                    |
| API routes look up records through the actor, never route model binding                                                                                                              | `tests/Feature/ApiRouteConventionsTest.php`                                                                                                                                                                                                                                    |
| Domain code receives the acting user as a parameter, never `auth()` or `request()`                                                                                                   | "receives the acting user" in `ArchitectureTest`                                                                                                                                                                                                                               |
| Resources and Inertia props never list secrets                                                                                                                                       | "never lists secrets" in `ArchitectureTest` (resources, `app/Http/Props`, `HandleInertiaRequests`)                                                                                                                                                                             |
| `SystemPermission` holds only permissions that keep access control recoverable                                                                                                       | "reserves SystemPermission" in `vendor/shipwithian/shipkit-core/tests/BootstrapAccessControlActionTest.php`                                                                                                                                                                    |
| The protected marker never changes after creation                                                                                                                                    | `ensureProtectionIsUnchanged()` on `Role`, `Permission`, and `User`; `tests/Feature/AccessControl/AccessControlInvariantsTest.php`                                                                                                                                             |
| Only the access-control bootstrap writes `is_protected`                                                                                                                              | `vendor/shipwithian/shipkit-core/tests/ProtectedMarkerTest.php` (app, seeders, factories, routes, tests; exceptions listed in `shipkit.architecture.protected_marker_exceptions` with a reason)                                                                                |
| Permission strings in the frontend are seeded permissions                                                                                                                            | `tests/Feature/FrontendPermissionsTest.php`                                                                                                                                                                                                                                    |
| A database cascade never deletes guarded rows without a recorded reason                                                                                                              | `vendor/shipwithian/shipkit-core/tests/GuardedTablesTest.php`                                                                                                                                                                                                                  |
| Every factory resolves to an existing model                                                                                                                                          | `tests/Feature/DomainFactoryResolutionTest.php`                                                                                                                                                                                                                                |
| A guard that counts what remains holds under concurrent writes                                                                                                                       | The `concurrency` group (`tests/Feature/AccessControl/LastSuperAdminConcurrencyTest.php`), run on MySQL and Postgres by the `concurrency` job in `.github/workflows/tests.yml`; a new counting guard still relies on review to add its case                                    |
| Relationship invariants hold however a relation is changed                                                                                                                           | `GuardsPivotInvariants`; `tests/Feature/AccessControl/RelationshipInvariantsTest.php`; pivots must use the pivot trait ("guards invariants only through GuardsInvariants" in `ArchitectureTest`)                                                                               |
| Installer archives contain every tracked file except documented exclusions                                                                                                           | `tests/Feature/TemplateArchiveTest.php`                                                                                                                                                                                                                                        |
| Changes to the checks need the maintainer; agents merge only project-owned feature code                                                                                              | The repository's CODEOWNERS file, with code-owner review required on `main` by branch protection the maintainer applies; `tests/Feature/CodeOwnersTest.php` fails when CODEOWNERS names a path that does not exist. The handoff evidence in `implement` still relies on review |
