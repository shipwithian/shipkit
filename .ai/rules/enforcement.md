# Enforcement

Each architecture rule and what makes it fail when broken. A rule whose enforcer is only partial says so; when an agent breaks one of those twice, run `/correct` and move it up to a check. Keep this table current in the same change that adds, enforces, or drops a rule.

| Rule                                                                                                                                                                                 | Enforced by                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The domain never depends on `app/Http`                                                                                                                                               | `arch()` in `tests/Unit/ArchitectureTest.php`                                                                                                                                                    |
| A context's internals (Models, Enums, Policies, Services) are used only by itself, `App\Models`, factories, seeders, and `app/Http`; its public surface only by the domain and those | `arch()` per discovered context in `ArchitectureTest`                                                                                                                                            |
| The shared kernel (`ShipKit\Core`) never depends on the application                                                                                                                  | `arch()` in `packages/shipkit-core/tests/CoreBoundaryTest.php`                                                                                                                                   |
| ShipKit's checks run in every project                                                                                                                                                | `php artisan shipkit:verify` in `composer ci:check` fails when the `ShipKit` testsuite is missing from `phpunit.xml`                                                                             |
| Guarded models are mapped and use `GuardsInvariants`                                                                                                                                 | `ShipKitServiceProvider` refuses to boot with an unguarded mapped model; `shipkit:verify` also fails on an unmapped one or a missing `config/shipkit.php`                                        |
| Actions end in `Action` and have `handle()`; Queries end in `Query`                                                                                                                  | `arch()` in `ArchitectureTest`                                                                                                                                                                   |
| Domain exceptions extend `DomainException`; contexts never throw `ValidationException`                                                                                               | `arch()` in `ArchitectureTest` (Authentication is the listed exception)                                                                                                                          |
| Controllers never use `DB` or query models                                                                                                                                           | `arch()` and "keeps Eloquent queries out of controllers" in `ArchitectureTest`                                                                                                                   |
| Aggregate invariants hold for every caller                                                                                                                                           | `GuardsInvariants` (events, silenced events, bulk writes); `tests/Feature/AccessControl/AccessControlInvariantsTest.php`, `tests/Feature/CreationInvariantsTest.php`                             |
| No bulk writes on guarded aggregates                                                                                                                                                 | `GuardedBuilder`; "guards invariants only through GuardsInvariants" in `ArchitectureTest`                                                                                                        |
| No raw `DB::table()` or SQL writes on guarded tables                                                                                                                                 | `tests/Feature/GuardedTablesTest.php`, with tables discovered from `GuardsInvariants` models                                                                                                     |
| Every Action, Query, and domain exception is listed in its context rule file                                                                                                         | `ArchitectureTest`                                                                                                                                                                               |
| HTTP and feature test folders are named after a context                                                                                                                              | `ArchitectureTest`                                                                                                                                                                               |
| Agent skills have valid frontmatter, licenses, and live path references                                                                                                              | `tests/Feature/AgentToolingTest.php`                                                                                                                                                             |
| Committed `CLAUDE.md` and `AGENTS.md` match `.ai/guidelines`                                                                                                                         | `tests/Feature/AgentToolingTest.php`                                                                                                                                                             |
| Code style and types                                                                                                                                                                 | Pint, `vp check`, PHPStan level 7, all in `composer ci:check`                                                                                                                                    |
| Protected controller actions call `Gate::authorize()` first                                                                                                                          | `tests/Feature/RouteAuthorizationTest.php`: every action behind `auth` middleware, parsed; only `$user = $request->user();` may precede it                                                       |
| Policies check permissions, never role names                                                                                                                                         | "authorizes policies through permissions, never role names" in `ArchitectureTest`                                                                                                                |
| Form Requests contain no `authorize()` logic                                                                                                                                         | `arch()` in `ArchitectureTest`                                                                                                                                                                   |
| Routes carry no permission middleware                                                                                                                                                | `tests/Feature/RouteAuthorizationTest.php` (`can:`, `role:`, `permission:` on any app route)                                                                                                     |
| Inertia props and API resources list every exposed field                                                                                                                             | "lists every exposed field" in `ArchitectureTest` catches `toArray()`-style dumps; a raw model passed as a prop still relies on review                                                           |
| API routes that change state are throttled                                                                                                                                           | `tests/Feature/ApiRouteConventionsTest.php`                                                                                                                                                      |
| API routes look up records through the actor, never route model binding                                                                                                              | `tests/Feature/ApiRouteConventionsTest.php`                                                                                                                                                      |
| Domain code receives the acting user as a parameter, never `auth()` or `request()`                                                                                                   | "receives the acting user" in `ArchitectureTest`                                                                                                                                                 |
| Resources and shared props never list secrets                                                                                                                                        | "never lists secrets" in `ArchitectureTest`                                                                                                                                                      |
| `SystemPermission` holds only permissions that keep access control recoverable                                                                                                       | "reserves SystemPermission" in `ArchitectureTest`                                                                                                                                                |
| Permission strings in the frontend are seeded permissions                                                                                                                            | `tests/Feature/FrontendPermissionsTest.php`                                                                                                                                                      |
| A database cascade never deletes guarded rows without a recorded reason                                                                                                              | `tests/Feature/GuardedTablesTest.php`                                                                                                                                                            |
| Every factory resolves to an existing model                                                                                                                                          | `tests/Feature/DomainFactoryResolutionTest.php`                                                                                                                                                  |
| Relationship invariants hold however a relation is changed                                                                                                                           | `GuardsPivotInvariants`; `tests/Feature/AccessControl/RelationshipInvariantsTest.php`; pivots must use the pivot trait ("guards invariants only through GuardsInvariants" in `ArchitectureTest`) |
| Installer archives contain every tracked file except documented exclusions                                                                                                           | `tests/Feature/TemplateArchiveTest.php`                                                                                                                                                          |
